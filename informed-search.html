Informed Search Lab

f(n) = α·g(n) + β·h(n) — g(n) is the real accumulated path cost from start to n (not straight-line), h(n) is Euclidean distance from n to goal. With α=β (e.g. both 1) this is classic A*: since h never overestimates the true remaining distance, it's provably optimal here. β=0 is uniform-cost search (Dijkstra); α=0 is pure greedy best-first, which is fast but not guaranteed optimal.
Randomly regenerates maps and runs pure greedy best-first (α=0, β=1) on each until it finds one where greedy's path is longer than the true shortest path — then loads that map and animates it.
